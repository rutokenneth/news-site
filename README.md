# The Daily Dispatch — Online News Page

A simple, responsive online newspaper built using pure **HTML5** and **CSS3** (no JavaScript or external frameworks required).

## Features
- **Classic Newspaper Layout:** Includes a masthead, dateline bar, sticky section navigation, single-column editorial layout, and footer.
- **5 Distinct Multimedia Stories:**
  1. **Tech News (Text + Captioned Photos):** Coverage of geothermal-powered data centers in East Africa with captioned photography.
  2. **Science & Environment (Audio-Visual):** Embedded HTML5 `<video>` report on Lake Naivasha conservation drones.
  3. **Interview (Audio + Q&A):** Embedded HTML5 `<audio>` podcast clip paired with an edited Q&A and portrait.
  4. **Travel Feature (Multimedia Combination):** Narrative article on the Taita Hills combining an ambient forest `<audio>` track and a 3-photo captioned gallery.
  5. **Commentary (Editorial + Pull Quote):** Opinion piece on African language AI with an author byline, captioned photo, and pull quote.
- **Functional Hyperlinks:** All section links jump smoothly within the page, and all external reference links point to live, relevant websites (Reuters, UNEP, ArchDaily, Magical Kenya, Masakhane, etc.).
